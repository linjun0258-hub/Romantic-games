# 姿势插图放置目录

把插图按下面的规则放进本目录，页面会自动加载，**不需要改任何代码**。

## 命名规则

文件名 = `lib/positions.ts` 中该条目的 `id` + `.jpg`

例如：

```
positions/g-spot-sniper.jpg
positions/69.jpg
positions/ballerina.jpg
```

`id` 列表见 `17fei-main/lib/positions.ts`，页面上未配图的卡片也会直接显示对应的文件名提示。

## 支持的格式

- 推荐 `.jpg`（体积小、加载快）
- 如需用 `.png` / `.webp`，把 `lib/positions.ts` 里对应条目的 `illustration` 后缀一起改掉

## 统一视觉规格（建议）

| 项目 | 建议值 |
| --- | --- |
| 画幅 | 3:4 竖版（如 600×800） |
| 体积 | 单张 ≤ 150 KB |
| 风格 | 极简线性图标 / 扁平插画 |
| 线宽 | 全站一致 |
| 配色 | 主色 + 两个辅助色，不超过三色 |
| 图内文字 | 不要放，名称由页面渲染（利于多语言与 SEO） |
| 留白 | 四周留白比例一致 |

## 缺图时的表现

未放置图片的条目会自动显示虚线占位框，不会出现破图或布局跳动。页面顶部会显示「已配图 X / 总数」的进度。
